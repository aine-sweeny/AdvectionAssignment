Advection assignment. Áine Sweeny a.sweeny@pgr.reading.ac.uk
This project contains code to solve the one-dimensional linear advection equation and analyse the performance of several numerical schemes.
AdvectionAssignment.py : Run this to generate all results and save the figures in "plots" directory.

The script produces:
- Solution snapshots for schemes CTCS, FTBS and FTCS.
- Solution snapshots for CTCS, FTBS and Semi-Lagrangian (SLC) schemes.
- L2 error versus Courant number for schemes CTCS, FTBS and SLC.
- Phase and amplitude error for schemes CTCS, FTBS and SLC for sinusoidal initial condition.
- log-log convergence plot of l2 error versus grid spacing for schemes CTCS, FTBS and SLC.
